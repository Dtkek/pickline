Скачать конфиг
Game State Integration — официальный механизм Valve: игра сама сообщает, за кого вы играете и за какую сторону. Нужны два шага: «Подключить игру» кладёт конфиг в папку Dota, а в Steam у Dota 2 должен стоять параметр запуска -gamestateintegration (Steam → библиотека → Dota 2 → правый клик → Свойства → Параметры запуска). Без параметра игра конфиг не читает. Потом перезапустить Dota. Либо выберите героя руками или нажмите «это я».
Выберите своего героя — покажу стартовый закуп и порядок сборки из турнирных матчей.

Мой аккаунт

Подбор будет учитывать, на ком вы сами играете лучше: личный винрейт на герое и опыт. Нужна включённая в Steam настройка «Открытая история матчей». Если игра подключена через GSI, аккаунт подхватится сам.
