## Позиционирование

**Для кого:** игроки СНГ в рейтинге, которые доверяют цифрам больше, чем
ощущениям, и не платят за Dota Plus (или платят, но не понимают, откуда
её советы).

**Что обещаем:** «Драфт заполняется сам, совет — за секунду, и видно, из
чего он сложился». Не обещаем: победы, рост MMR, «гарантированный
контрпик» — бэктест этого не подтверждает, и тон проекта это запрещает.

**Отличия:**
- автоматически видит героев на экране — веб-сервисам героев вбивают руками;
- бесплатно, в отличие от Dota Plus;
- показывает объём выборки и разбор балла;
- открытый код (MIT) — снимает часть страха «стилер или бан».

**Барьеры (дыры воронки):**
1. Доверие: неподписанный exe, читает экран, кладёт конфиг в папку Dota.
2. Первый запуск: параметр `-gamestateintegration` в Steam, скачивание
   портретов, выбор области экрана.
3. Ключевые функции не проверены вживую на ПК: авторежим чтения экрана,
   роли с экрана.
4. Нечем мерить: нет счётчика запусков, который переживает пересборку.

## Traction goal

Предлагаемая цель (оценка, подтвердить у владельца):

- **Этап 1, закрытый тест:** 10–20 знакомых, из них **≥ 50% запускают
  приложение повторно через неделю**.
- **Этап 2, первые каналы:** 300 установок за месяц, из них **≥ 30%
  возвращаются через неделю**.

Главная метрика на всех этапах — повторный запуск через неделю (удержание),
а не число скачиваний.

## Предусловия до любого канала

Принцип роли: воронка важнее канала. Пока в воронке эти дыры, трафик
уйдёт в песок.

- [ ] Проверить в живом драфте на ПК: авторежим чтения экрана, роли с
      экрана, варды.
- [ ] Подписать exe. Для открытых проектов есть бесплатная подпись
      через SignPath — условия не перепроверялись.
- [ ] Ссылка на проверку VirusTotal для каждого релиза.
- [ ] Упростить первый запуск: пошаговая подсказка для GSI, портреты
      качаются сами.
- [ ] Анонимный счётчик запусков по согласию пользователя, который не
      обнуляется на пересборке.
- [ ] Проверить условия API STRATZ: можно ли раздавать снимок данных
      тысячам пользователей. Может оказаться жёстким ограничителем.
